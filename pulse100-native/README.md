# Pulse 100 — Android nativo

Jogo completo de reação em cadeia cromática para Android, desenhado integralmente por código com Java e Canvas.

## Recursos

- controle de um único toque;
- modo clássico com progressão infinita;
- desafio diário determinístico e offline;
- três rodadas por partida;
- partículas normais, prismas e partículas carregadas;
- recordes, progresso e configurações salvos localmente;
- efeitos neon, partículas, vibração e áudio sintético;
- sem cadastro, servidor ou conexão com a internet;
- compatível com Android 6.0 ou superior.

## Build

```bash
gradle -p pulse100-native :app:assembleDebug
```

O APK de teste é produzido em:

```text
pulse100-native/app/build/outputs/apk/debug/app-debug.apk
```
